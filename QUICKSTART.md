# Быстрый старт

Актуальная модель — полностью дообученная SigLIP 2.
См. [README](README.md): команды запуска готового пода и подготовки новой среды.
Для публикации с Mac: [GITHUB_PUBLISH](docs/GITHUB_PUBLISH.md).
Подробности обучения: [SIGLIP2](docs/SIGLIP2.md).
Личные настройки: скопировать `configs/pod.env.example` в `configs/pod.env`
и заполнить свои значения. Существующий файл на рабочем поде не перезаписывать.
