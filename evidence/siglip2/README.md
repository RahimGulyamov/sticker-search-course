# Результаты SigLIP 2

Файлы извлечены из переданного `siglip2_test_results.zip` без изменения чисел.
`history.jsonl`, `selection.json` и `evaluations/` фиксируют выбор эпохи 2 по dev.
`baseline_test/` и `selected_test/` содержат отдельный последующий test-прогон.
680 EN + 680 переводов RU, 86 уникальных целей; кандидаты — весь каталог 30 914.
Веса, индекс и большие обучающие артефакты находятся вне Git.
Абсолютные пути в JSON — пути исходного пода, а не файлы внутри этого репозитория.

Test уже использовался в предшествующем CLIP-эксперименте. Выбор эпохи SigLIP
сделан по dev; полностью новым слепым тестом этот набор не является.
Все тестовые цели — стикеры. OCR, открытки и качество генерации этими метриками
не оцениваются. Русские переводы не являются независимой человеческой оценкой.
